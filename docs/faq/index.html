Q

予約は必要ですか？

A

予約制のお店です。お電話（0428-24-4009）またはLINEからご予約ください。ご希望の日時をお伝えいただければ、こちらで空きをお調べします。

LINEで予約・相談する↗電話する0428-24-4009
Q

駐車場はありますか？

A

はい、3台分の駐車場をご用意しています。お車でお越しいただけます。満車のこともありますので、気になるときはご予約の際にお尋ねください。

Q

支払いは現金だけですか？

A

いいえ。現金のほか、クレジットカード・電子マネー・QRコード決済でのお支払いにも対応しています。

Q

営業時間と定休日を教えてください。

A

9:00から19:00まで営業しています。定休日は毎週月曜日と、第2・第3火曜日です。

Q

フェードは追加料金がかかりますか？

A

フェード・スキンフェードは、カットを含むメニューに＋300円で承ります。0.4mm以下の短さをご希望の場合も、同じ料金です。

Q

学生の料金はありますか？

A

高校生・中学生・小学生それぞれの料金をご用意しています。金額は料金表をご覧ください。

Q

髪型が決まっていなくても大丈夫ですか？

A

問題ありません。骨格や髪質、お仕事の決まりごと、ふだん手入れにかけられる時間をうかがったうえで、似合う形をご提案します。写真をお持ちいただけると、より確かです。

Q

場所はどこですか？

A

東京都青梅市東青梅3-9-15です。JR青梅線・東青梅駅が最寄りになります。詳しい道順は、店舗案内の地図をご覧ください。

Q

はじめてでも入りやすいですか？

A

はじめての方も多くお越しになります。仕上がりは「STYLE ARCHIVE」でご覧いただけますので、気になる髪型を見つけてからお越しいただくのもおすすめです。ご不安な点は、LINEで先にご相談いただけます。
